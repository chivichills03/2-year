# Lab 3 — Функции и триггеры в PostgreSQL

**Дисциплина:** Информационная безопасность баз данных
**Цель:** получить навыки написания хранимых процедур, функций и триггеров в PostgreSQL и научиться использовать их для автоматизации и аудита изменений данных.

### 5. Триггер аудита со спецпеременными
Реализован журнал аудита изменений с использованием специальных переменных триггеров PostgreSQL:

| Переменная | Назначение |
|---|---|
| `TG_TABLE_NAME` | какая таблица изменилась |
| `TG_OP` | тип операции (`INSERT` / `UPDATE` / `DELETE`) |
| `OLD` | старые значения строки (для `UPDATE`/`DELETE`) |
| `NEW` | новые значения строки (для `INSERT`/`UPDATE`) |
